Apply file additions, deletions, updates, and renames in one patch:

*** Begin Patch
[one or more file operations]
*** End Patch

Start each operation with one of these headers:

*** Add File: <path> - create a new file. Prefix every content line with +.
*** Delete File: <path> - remove an existing file. Nothing follows.
*** Update File: <path> - update an existing file. An optional *** Move to: <path> line renames it.

Within an update, prefix unchanged lines with a space, removed lines with -, and added lines with +.
Use @@ or @@ <context> to locate a change; include enough unchanged context to identify it uniquely.
Use *** End of File after the final change when it must match the end of the file.

Example patch:

```
*** Begin Patch
*** Add File: hello.txt
+Hello world
*** Update File: src/app.py
*** Move to: src/main.py
@@ def greet():
-print("Hi")
+print("Hello, world!")
*** Delete File: obsolete.txt
*** End Patch
```
